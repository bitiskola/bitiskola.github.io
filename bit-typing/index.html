Important: macOS security step required

The app will not open normally after download. You must verify it once through Terminal before the first launch.

macOS Gatekeeper blocks apps that are not signed and notarized by Apple. BIT Typing is an independent open-source project, so the macOS builds are not notarized yet. This is a normal protection — not a problem with the app itself.

After downloading, you need to remove the quarantine attribute using Terminal. The short video below walks you through the exact steps.
